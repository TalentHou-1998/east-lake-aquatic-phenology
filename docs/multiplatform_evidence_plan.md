# 多平台、无定位媒体证据改造计划

| 阶段 | 输入 | 产出 | 检查点 |
|---|---|---|---|
| 1. 平台盘点 | 现有采集器、GitHub 公开项目 | `config/platform_sources.json`、`docs/platform_adapter_research.md` | 平台、许可证和风险路径可核 |
| 2. 候选召回 | 一级地标、区域词、植被与活动词 | 扩展后的 `media_collection_plan.json` | 不以平台定位作为召回条件 |
| 3. 统一导入 | 平台导出 JSON、媒体 URL/本地文件 | 各平台统一 CSV 与媒体目录 | 无作者身份、可去重、可追溯 |
| 4. 证据抽取 | 正文、图片、视频帧、POI | `location_evidence.csv` | 正文/OCR/画面/平台证据分列保存 |
| 5. 综合判定 | 地名词典与证据权重 | 一级地标候选、置信度、待复核原因 | 检索词不能单独成为位置证明 |
| 6. 地图与归档 | 已核验记录和媒体 | 私有核验地图、地标/年份归档 | 媒体引用完整，原始 POI 保留 |

当前数据基线：归档媒体 1,504 个，其中微博 734、抖音 299、高德地图 285、小红书 145、百度地图 33、快手 8；美团、大众点评、两步路、可颂和 B 站均为 0。该分布说明现有样本存在明显平台偏斜，需要补采，不能直接用于跨平台频率比较。
