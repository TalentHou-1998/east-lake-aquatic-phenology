# 东湖媒体一级 POI 与年度归档方案

## 设计目标

媒体归档不再使用平台返回的几十种细碎 POI 作为顶层目录，而是先归入容易在地图上识别的一级地标，再按发布时间年份分层。平台原始 POI、地址和来源链接仍保留在索引及地图详情中，用于位置一致性核验。

## 文件结构与命名

```text
media_by_landmark_year/
└── 东湖磨山景区/
    ├── 2025/
    │   ├── 东湖磨山景区-20250605-155203-小红书-001.webp
    │   └── 媒体索引.csv
    ├── 2026/
    └── 年份未知/
```

三位序号在每个“一级地标 × 年份”文件夹内独立编号。没有可靠发布时间的文件进入 `年份未知/`，文件名中的时间写作 `发布时间未知`，不以采集时间替代。

## 重建命令

```bash
python3 src/build_media_collection_plan.py
python3 src/rebuild_poi_media_archive.py --project-root .
python3 src/import_poi_archive_to_posts.py --project-root .
python3 src/export_map_site.py --project-root . --site-dist sites/east-lake-map/dist
```

`media_collected/` 和原始平台数据保持不变。新归档默认使用硬链接，因此可回溯且不会重复占用媒体文件大小。

## 宽松检索原则

检索保留一级地标作为空间锚点，但不再要求非常具体的桥、栈道或小湖湾名称。每个地标使用多个常见写法，并与荷花、荷叶、残荷、水草、浮萍、湿地、池塘、湖边、钓鱼、划船、航拍、风景、散步、骑行、栈道、水葫芦、打捞、返青、盛花和枯黄等宽松词组合。正式归档仍执行发布时间、区域证据和水生植被语义检查。
