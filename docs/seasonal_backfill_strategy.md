# 1—5月季节偏差补采方案

当前数据明显偏向荷花盛花期。检索阶段不再把水生植被词作为唯一入口，而改为“地点锚定、季节召回、媒体后筛”。

## 检索层级

1. **春季补采**：POI＋早春、春游、踏青、清明、春分、谷雨、三月、四月、五月、新绿、返青、雨后等。
2. **中性活动**：POI＋周末、散步、骑行、观鸟、露营、遛娃、晨跑、游园、Vlog、航拍等。这类内容即使文案没有植被词，画面仍可能记录湖岸和水面。
3. **四季平衡**：POI＋春/夏/秋/冬，分别进入对应月份候选池。
4. **植被诊断**：荷花、残荷、水草、浮萍等词保留，但排序在季节和中性活动之后。

可继续扩展的日历入口包括春节、元宵、寒假、开学、植树节、妇女节、劳动节、青年节和端午；天气入口包括初晴、阴天、雾、雨后、降温和回暖；行为入口包括 CityWalk、写真、遛弯、慢跑、野餐、放风筝、赏鸟、亲子和毕业照。它们只承担媒体召回，不直接证明拍摄地点、拍摄日期或植被阶段。

## 时间配额

- 第一轮优先补采1—5月，每月至少达到50条候选记录。
- 搜索结果归档时使用发布时间月份过滤；发布时间未知的记录不进入月度补采集。
- 春季、节事、中性活动和四季平衡批次不要求文案出现水生植被词；媒体先保留，再通过OCR和画面核验水面与水生植被。
- 配额用于控制采样均衡，不表示所有候选都具有研究价值。最终仍需通过正文、OCR、画面和地点证据复核。

## 当前缺口与调度顺序

首轮补采前，1—5 月分别为 14、9、14、20、26 条；首轮补采并合并已保存的多平台有效批次后，分别为 14、9、17、26、27 条。下一轮按缺口从大到小调度为：2 月、1 月、3 月、4 月、5 月。每个 POI 先运行一个关键词小批次，观察平台结果的年份与月份分布后再扩量，避免同一热词连续返回同质内容。

## 运行示例

```bash
python3 scripts/run_place_media_collection.py \
  --unit-id BP01 --platform xhs \
  --strategy spring_backfill --keyword-start 0 --keyword-count 1 \
  --target-months 1-5 --max-notes 10 --execute
```
