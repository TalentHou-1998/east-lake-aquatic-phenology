# 标注规范：武汉东湖水生植被物候

- 版本：v1.0
- 制定日期：2026-11-05
- 任务类型：多标签植物类型 + 有序覆盖度 + 物候阶段 + 位置一致性
- 标注载体：CSV/图像查看器；后续可迁移至 Label Studio

## 1. 植被生长阶段（v2 四阶段）

| 标签 | 可操作定义 | 常见混淆 |
|---|---|---|
| `growth_start` | 植被开始生长：可见新芽、新生小叶、稀疏新生植株或当年植株刚出水 | 远景无法分辨时标 `unknown` |
| `fully_grown` | 植被生长完全：叶片充分展开、群落覆盖相对稳定；花蕾、开花和结实但整体仍健康时均归此类 | 局部花朵或果实不再单独形成阶段 |
| `decline_start` | 植被开始衰败：出现可辨认的黄化、枯边、倒伏、叶片减少或季末衰退，但仍有显著活体植被 | 污染或机械损伤需在备注说明 |
| `declined` | 植被已经衰败：大部分植株枯黄、倒伏、腐烂，仅余枯茎残体或基本无当年活体叶片 | 不能把人为清理后的空水面直接判作衰败 |
| `unknown` | 分辨率、遮挡或构图不足以可靠判断 | 不用文案猜测替代画面证据 |

历史标签迁移：`leaf/flower_bud/flowering → fully_grown`，`fruiting/senescent → decline_start`，`dormant → declined`，`emergence → growth_start`。迁移结果保留在 `notes`，不得当作新增人工真值。

## 1.1 媒体价值

- `meaningful`：画面、文案、时间或位置至少一项能支持水生植被/空间核验。
- `meaningless`：无法支持植被、位置或时间判断。系统默认从地图隐藏，但保留原始记录和撤销入口。
- `unknown`：尚未人工判断。

## 2. 覆盖度

- `0`：目标水生植被不可见。
- `<10%`：零散斑块。
- `10-30%`：局部连续但水面仍占主体。
- `30-60%`：植被与开阔水面均占显著比例。
- `>60%`：大部分可见水面被植被覆盖。
- `unknown`：近景、遮挡或镜头方向不适合估算。

覆盖度只对照片/关键帧中的“可见水域”估计，不外推至整个东湖。

## 3. 位置一致性

| 情形 | 标签 |
|---|---|
| 明确地标、岸线、桥梁或建筑与 POI 相符 | `match` |
| 位于同一湖区/景区，但无法确定具体拍摄点 | `plausible` |
| 画面证据明确指向东湖以外或其他景区 | `conflict` |
| 没有足够背景信息 | `unknown` |

## 4. 边界规则

- 发布 POI、IP 属地和文案中的地点均不能单独当作拍摄地点真值。
- 出现“去年、库存、回忆、补发、搬运、转载”等词时，发布时间不能直接作为拍摄时间。
- 视频至少抽取开头、中段、结尾及场景切换关键帧；多场景视频分别标注后再汇总。
- 水华、丝状藻和漂浮垃圾与高等水生植物分开记录。
- 画面中出现人脸、车牌、手机号等信息时标记为需脱敏。

## 5. 人工审核与一致性

- 模型预标注不能直接作为真值；每条记录必须有人审状态。
- 首批 50 条全部人工复核；之后每批至少抽检 20%。
- 随机 20% 样本由两名标注者独立标注。
- 有序的物候/覆盖度使用二次加权 Cohen's κ；位置类别使用普通 Cohen's κ。
- κ ≥ 0.8 为优秀，0.6–0.8 需复核分歧，κ < 0.6 时暂停并补充边界规则后重标。
