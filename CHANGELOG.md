# Changelog

All notable changes are documented here.

## [0.5.0] - 2026-11-06

### Added

- Four-stage aquatic vegetation annotation model.
- Reversible `meaningless` media-value label and map filtering.
- Baidu Map place-album ingestion with unknown-time handling.
- Public-release privacy gate, environment placeholders and GitHub CI.
- Detailed user manual, system design and ethics review.

### Changed

- Consolidated the working dataset to 756 local records.
- Migrated 24 legacy visual labels to the new stage vocabulary while preserving provenance notes.

### Security

- Browser sessions, raw/processed records, third-party media, deployment metadata and credentials are excluded from Git.
