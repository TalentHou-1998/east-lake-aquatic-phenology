# 武汉东湖水生植被社交媒体物候数据集

本仓库提供多平台媒体记录的清洗、统一标注和百度遥感影像地图核验代码。GitHub 版本不包含登录状态、原始/处理数据、第三方媒体或第三方采集器。

## 研究范围

- 区域：武汉东湖及东湖生态旅游风景区
- 时间：2018-01-01 至 2026-10-30
- 平台：高德、抖音、可颂、快手、微博、百度地图地点相册
- 初始目标：每个平台 100 条可核验公开内容；后续增量不设硬性条数上限
- 用途：从公开照片/视频、文案、发布时间和发布 POI 推断水生植被生长状态与物候

## 目录

- `config/`：关键词、采集参数和质量规则
- `data/raw/`：平台原始导出，仅限内部研究使用
- `data/interim/`：去重、字段统一后的中间数据
- `data/processed/`：脱敏且完成质量检查的数据
- `media/`：研究所需的照片、视频或关键帧，不对外再发布
- `media_collected/`：按“区域/地点/平台”重组的媒体素材库，不对外再发布
- `docs/`：字段与人工标注规范
- `src/`：清洗、去重和质量检查脚本
- `vendor/`：经核验的上游采集项目；保留其原许可证

## 当前采集策略

1. 小红书/抖音/快手/微博：以东湖小空间单元和景点别名生成关键词矩阵，用 `MediaCrawler` 低频分批获取实际媒体。
2. 媒体：最终只归档存在图片或视频的记录，目录为“区域/地点/平台”，文件名以“采集时间+地点”开头。
3. 高德：官方 API 用于 POI 地址和 GCJ-02 坐标标准化；用户评价采用登录状态下的低频浏览器采样。
4. 可颂：先验证抖音同步内容的覆盖率，再决定是否需要单独的 App 端采样。
5. 原始数据访问级别为 `raw`；作者昵称、账号 ID、人脸和车牌不得进入公开产物。
6. 百度地图地点相册只保存页面公开展示的照片和地点信息；页面没有显示单张照片发布时间时保持为空，不根据链接或文件时间推测。
7. 百度和高德不属于 `MediaCrawler` 支持平台，继续使用独立地点相册/评价适配器；不绕过验证码和访问控制。

## 快速开始

```bash
python3 -m compileall -q src
node --check sites/east-lake-map/dist/app.js
python3 src/check_public_release.py --root .
```

地图生成需要本地数据和 ImageMagick：

```bash
python3 src/export_map_site.py \
  --project-root . \
  --site-dist sites/east-lake-map/dist
python3 -m http.server 4173 --directory sites/east-lake-map/dist
```

详细采集、处理和标注步骤见 `docs/user_manual.md`。

## 在线核验功能

- 遥感影像底图上查看帖子/相册点位及关联媒体。
- 植被阶段统一为“植被开始生长、植被生长完全、植被开始衰败、植被已经衰败”，无法判断时保留“尚未判断”。
- 可记录发布地点与目视地点的一致性、植被阶段、媒体价值和备注。
- 将媒体价值标为“无意义”后，点位默认从地图和列表隐藏；勾选“显示已标为无意义的点位”可恢复查看并撤销判断，原始记录不被删除。
- 人工判断保存在当前浏览器本地，可导出 CSV 备份。

## 位置与时间解释

- 平台 POI 是用户挂载位置，不必然等于拍摄位置。
- `publish_time` 是发布时间，不必然等于拍摄时间。
- 高德坐标通常为 GCJ-02；未经转换不得与 WGS84 或 BD-09 直接计算距离。
- 物候结论以旬/月为尺度，不将单条社交媒体帖子解释为精确观测日期。

## 安全与发布边界

- API Key、Token 和代理地址只允许写入本机 `.env`；仓库中的 `.env.example` 只包含占位符。
- `data/`、`media/`、浏览器 profile、站点私有部署元数据和 `vendor/` 不进入 GitHub。
- 发布前运行 `python3 src/check_public_release.py --root .`；检查器不会回显疑似密钥值。
- 第三方照片、视频和文案版权仍归原权利人所有；本仓库不授予其再分发许可。
